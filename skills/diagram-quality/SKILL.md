# 图表质量技能

- 图标题与副标题先说明主题，再进入细节。
- 每条边的方向应从“发起/拥有/子类型”指向“接收/被拥有/父类型”。
- 选择方向：层级和流程用 TB；类、组件、部署、ER 常用 LR。
- 节点标签保持业务语言，技术标识放在 attributes 或 stereotype。
- 关系标签只写角色、基数、动作或条件，不写长段落。
- 长解释放入 notes，不要塞进节点。
- 每张图控制在 18 个节点内；超过时按层、按场景或按生命周期拆分。
- 自检：孤立节点、悬空关系、重复 id、方向矛盾、状态无出口、时序 order 重复。
